# Lumos Wickery

> A responsive multi-page storefront web app built with **React, TypeScript, Vite, and Tailwind CSS** (shadcn/ui components).

![React](https://img.shields.io/badge/React-20232A?style=flat&logo=react&logoColor=61DAFB)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat&logo=typescript&logoColor=white)
![Vite](https://img.shields.io/badge/Vite-646CFF?style=flat&logo=vite&logoColor=white)
![TailwindCSS](https://img.shields.io/badge/Tailwind-38B2AC?style=flat&logo=tailwindcss&logoColor=white)

## Pages

- **Home**: landing page with product highlights
- **Shop**: product catalog with `ProductCard` components
- **About** · **Blog** · **Contact**: supporting content pages
- Custom `Header` / `Footer` layout, 404 handling

## Tech stack

- **React 18 + TypeScript** on **Vite** for fast dev and clean builds
- **Tailwind CSS** with shadcn/ui primitives for the component system
- ESLint-configured, strict TypeScript (`tsconfig.app.json`)

## Quick start

```bash
git clone https://github.com/Aditi21372/lumos-wickery-glow.git
cd lumos-wickery-glow
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
